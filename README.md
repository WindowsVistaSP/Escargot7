# Escargot7
在Windows Phone 7/8上登录Escargot？！

目前还在测试当中，还有一些bug，正式版预计在10月之前发布

当前功能：

1.可以登录你的Escargot/Crosstalk*账号；
2.可以删改你的联系人并与之聊天；
3.可以修改你的状态和昵称；
4.可以设置“记住密码”和“启动时自动登录”。

*:本软件的默认配置只能登录Escargot的账号，如果要登录Crosstalk账号请在设置里将服务器改为ms.msgrsvcs.ctsrv.xyz，端口为1684

当前缺陷：

1.无法加载头像，无法设置个人消息，无法发送和接收离线消息，无法发送和接收文件，无法发起或接收游戏请求，无法接收窗口晃动，无法接收传情动画(MSNP4原生不支持)；
2.无法挂后台接收消息，每次启动时都会重新登录；
3.有时候会闪退

如果对MSNP4协议感兴趣，可以查看MSNP4.txt
